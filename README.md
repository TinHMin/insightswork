# insightswork
This is the places where I would keep the resources for data analysis. Thanks to Professor Wilcoxen of Maxwell School of Public Affairs and Citizenship, Syracuse University, I've got links to amazing resources. My collection is building up on his effort to my personal usage and public.

## Python Basics
[Python for Beginner](https://opentechschool.github.io/python-beginners/en/getting_started.html#what-is-python-exactly)

[Documenting Python Code](https://realpython.com/documenting-python-code/)

An excellent guide to writing comments and documentation.

[Markdown Cheatsheet](https://github.com/adam-p/markdown-here/wiki/Markdown-Cheatsheet)

A great quick reference guide

[Documentation for Pandas](https://pandas.pydata.org/docs/index.html)

The official documentation for Pandas.

[Google Document Translation Service](https://translate.google.com/?sl=en&tl=es&op=translate)

Able to translate docx, pdf, pptx, and xlsx files to and from many languages.

[Python Documentation at Codeacademy](https://www.codecademy.com/resources/docs/python)

Quick access to tips on key Python topics.

## Visualization in python
[Matplotlib Colormap Documentation](https://matplotlib.org/2.0.2/users/colormaps.html)

A guide to the colormaps and palettes available.

[The Python Graph Gallery](https://python-graph-gallery.com/)

An excellent and very broad collection of example graphs, with code.

[Documentation and Tutorial for Matplotlib](https://matplotlib.org/stable/plot_types/index.html)

The website explains types of plot including animated ones, provides documents, examples and tutorials to create graph using matplotlib. 

[Seaborn Data Visualization Library](https://seaborn.pydata.org/index.html)

Seaborn is a Python data visualization library based on matplotlib. It provides a high-level interface for drawing attractive and informative statistical graphics.

[Type Hint Cheatsheet](https://mypy.readthedocs.io/en/stable/cheat_sheet_py3.html)

Quick reference for type hints for more complex data types.

[Documentation for Geopandas](https://github.com/adam-p/markdown-here/wiki/Markdown-Cheatsheet)

An extension of Pandas for handling spatial data.

## US Data Sources
[CDC Behaviorial Risk Factor Surveillance System (BRFSS)](https://www.cdc.gov/brfss/index.html)

Health-related risk behaviors, chronic health conditions, and use of preventive services.

[CDC Main Data Page](https://data.cdc.gov/)

Main entry point for CDC data.

[Census Documentation]

Selected information useful in working with Census data

[Census Shapefiles](https://www.census.gov/geographies/mapping-files/time-series/geo/tiger-line-file.html)

Links to the key download pages a the Census

[Census State and Local Government Finance Data](https://www.census.gov/programs-surveys/gov-finances.html)

Available annually.

[Central New York Real Estate Transactions](https://www.syracuse.com/realestate/transactions/)

From 2020 and updated weekly

[City of Syracuse Open Data Portal](https://data.syr.gov/)

Includes GIS data.

[Dartmouth Atlas of Healtcare Data](https://data.dartmouthatlas.org/)

Extensive data from Medicare and other sources.

[Data.gov](https://data.gov/)

The federal government's open data access portal.

[EIA US Energy Atlas](https://atlas.eia.gov/search)

Extensive GIS data on the US energy sector.

[EM-DAT](https://www.emdat.be/)

International Disaster Database

[Federal Election Commission](https://www.fec.gov/data/browse-data/?tab=bulk-data)

Data on political contributions.

[FEMA Flood Map Service Center](https://msc.fema.gov/portal/home)

Find flood maps by using the "Search All Products" tool and selecting "NFHL Data-County"

[FEMA Open Data](https://www.fema.gov/about/openfema/data-sets)

FEMA's open data repository

[General Social Survey (GSS)](https://gss.norc.org/)

Survey of US adults covering a wide range of topics and going back 50 years.

[ICPSR](https://www.icpsr.umich.edu/web/pages/)

A long-standing university consortium that provides access to many social science datasets.

Life-M
Intergenerational database of 15 M individuals born in Ohio or North Carolina

Massachusetts Property Tax Parcels
Shapefiles and data on tax parcels in the state.

Microsoft Building Footprint Data
Datasets of building footprints by state.

MIT Election Lab
A wide range of datasets on US Federal elections.

National Historical Geographic Information System
Summary tables and time series GIS data for the US back to 1790.

New York State
The NYS open data access portal.

New York State Department of Education
Comprehensive data about New York schools.

New York State GIS Clearinghouse
An extensive repository of NYS GIS data.

New York State Property Tax Data
Data on all tax parcels in New York. Provided by county for parcel centroids.

Public Opinion and Social Attitudes Data
Extensive list of databases curated by the Michigan State University library.

SU Library Numeric Data Resources Page
SU maintains a page with lots of links to data sources.

US EPA
Entry page for EPA data.

US International Trade Commission (USITC)
Data on tariffs and trade.
